# golden-tasks · 基准任务集

固定的 6 个代表性任务，覆盖本 kit 的全部流水线技能。**任务输入一经固定不得修改**（修改 = 换基准，需重跑全部历史版本建立新基线）。

| ID | 覆盖技能 | 场景 |
|----|---------|------|
| T1 | rd-brainstorm | 模糊需求 → 方案探索 |
| T2 | rd-plan | 已定方案 → 任务拆分 |
| T3 | rd-execute + rd-review | 写作/执行 → 交付 |
| T4 | systematic-debugging + verification | 症状 → 根因分析 |
| T5 | tech-review / rd-review | 产物 → 质量审查 |
| T6 | 全流水线 | 端到端产物链 |

## 使用规则

1. 每个任务卡包含：**固定输入**（原样发给被测智能体）、**期望产物**（文件系统核对）、**质量评分点**（喂给 judge）。
2. 评测环境：干净工作区 + 加载本 kit（AGENT.md + skills + rules），模型与温度固定并记录在报告里。
3. 每任务建议跑 2~3 次取均值；不同次运行间清空上下文与工作区。
4. 期望产物是**机器可核对**的（存在性检查可脚本化），质量评分点由 judge/人工评。
5. 写作/文档型任务（交付物为文本/大纲/报告，如 T3/T5/T6）的期望产物与评分点 = 非代码任务「判据先行」形态的实例化：按 `thinking-checklist` 简化档 · 最小交付卡「验收核点节」模板设计（动笔前先定核点：内容出处 / 覆盖 / 边界 / 形式）。
