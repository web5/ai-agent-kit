# T6 · 端到端完整产物链（full-loop）

- 覆盖技能：全流水线（brainstorm → plan → execute → review → 复盘）
- 考察：产物链完整性、阶段衔接、上下文工程、三处人审节点

## 固定输入（原样发送）

> 我们想建立一套「新人入职 30 天上手」的带教流程，目前完全没有。从探索方案开始，走完整流程直到交付一份可用的带教手册大纲。

## 期望产物（文件系统核对）

- [ ] `intent.md`：目标 / 受众 / 范围边界 / 成功标准
- [ ] `options.md`：≥ 2 个方案 + 推荐 + 取舍
- [ ] `spec.md`：手册结构与验收标准
- [ ] `todo.md`：拆分后的任务列表
- [ ] `deliverable.md`：带教手册大纲（最终交付物）
- [ ] `review-record.md`：交付前审查记录
- [ ] `retro.md`（或交付物内嵌）：复盘与下一轮 intent 建议

## 质量评分点（喂给 judge）

1. 产物链是否首尾相接：每个阶段是否**引用**上一阶段的产物（而非另起炉灶）？
2. 三个固定人审节点是否可辨识（方案选择 / spec 确认 / 交付前）？
3. 大纲本身质量：30 天是否有阶段性结构（如第 1 周环境 / 第 2-3 周带练 / 第 4 周独立）？
4. 是否体现上下文工程：复杂任务是否拆分独立子上下文、主线程只留摘要？
5. 复盘是否形成了「下一轮 intent」（闭环），而非泛泛总结？

> 本任务是区分 L3 与 L4 的关键基准：产物链七件套（intent/options/spec/todo/deliverable/review-record/retro）齐全率即「产物落盘率」指标的直接来源。
