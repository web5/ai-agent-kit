# 审查清单（通用）

每次做方案 / 文档 / 对外能力相关改动时，对照此清单逐项检查。

## 权限与访问控制

- [ ] 是否涉及权限？→ 如需，定义清晰的角色与最小权限模型。
- [ ] 身份凭证是否合理失效？→ 登出 / 过期机制明确。
- [ ] 不同凭证是否可区分用途？→ 避免一类凭证可互换。

## 敏感信息处理

- [ ] 密码 / 密钥是否加密存储？→ 必须哈希 / 加密。
- [ ] 敏感字段是否脱敏展示？→ 按规则掩码。
- [ ] 敏感配置是否入代码库？→ 走环境变量 / 密钥管理。
- [ ] 是否防越权 / 越界访问？→ 输入校验与权限校验。

## 对外交付物安全

- [ ] 是否限制访问频率？→ 必要限流。
- [ ] 是否有操作记录？→ 关键操作留痕。
- [ ] 是否限制输入规模？→ 内容 / 请求大小限制。
- [ ] 来源是否白名单？→ 禁止回退到「全部允许」。

## 暴露与日志

- [ ] 是否启用基础安全防护？→ 防嵌入 / 防嗅探等。
- [ ] 是否泄露内部错误？→ 生产环境返回通用提示，详情仅记日志。
- [ ] 是否使用结构化日志？→ 避免裸打印。

## 运行与保障

- [ ] 是否有质量校验？→ 自动化检查（拼写 / 链接 / 格式）。
- [ ] 是否暴露敏感资源到公网？→ 仅内网 / 授权访问。
- [ ] 是否有版本与备份策略？→ 历史可追溯。
- [ ] 是否有容错/重试策略？→ 故障可恢复。
