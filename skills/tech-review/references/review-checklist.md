# 审查清单（通用）

每次做方案 / 文档 / 对外能力相关改动时，对照此清单逐项检查。

## 权限与访问控制

- [ ] 是否涉及权限？→ 如需，定义清晰的角色与最小权限模型。
- [ ] 身份凭证是否合理失效？→ 登出 / 过期机制明确。
- [ ] 不同凭证是否可区分用途？→ 避免一类凭证可互换。

## 敏感信息处理

- [ ] 密码 / 密钥是否加密存储？→ 必须哈希 / 加密。
- [ ] 敏感字段是否脱敏展示？→ 按规则掩码。
- [ ] 敏感配置是否入代码库？→ 走环境变量 / 密钥管理。
- [ ] 是否防注入 / 越权？→ 参数化与鉴权校验。

## 对外契约安全

- [ ] 是否限制调用频率？→ 必要限流。
- [ ] 是否有操作记录？→ 关键操作留痕。
- [ ] 是否限制输入规模？→ 上传 / 请求大小限制。
- [ ] 来源是否白名单？→ 禁止回退到「全部允许」。

## 暴露与日志

- [ ] 是否启用安全响应头？→ 防嵌套 / 嗅探等。
- [ ] 是否泄露内部错误？→ 生产环境返回通用提示，详情仅记日志。
- [ ] 是否使用结构化日志？→ 避免裸打印。

## 运行与备份

- [ ] 是否有健康检查？→ 探活端点。
- [ ] 敏感端口是否暴露公网？→ 仅内网 / 本机。
- [ ] 是否有备份策略？→ 定期自动备份。
- [ ] 是否有健康检查与重启策略？→ 故障自愈。
